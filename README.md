# Schema, vecka 45
###### Apputveckling i molnet, vecka 3 av 6

## Introduktion

Hur lagrar vi information så att den finns kvar även efter att våra Lambda-funktioner har körts färdigt? Den här veckan introducerar vi databaser och lär oss hur vi kan använda DynamoDB för att lagra och hantera data i våra serverlessapplikationer.
Vi går igenom grunderna i NoSQL och databasmodellering, samt hur vi strukturerar vår data med hjälp av partition keys och sort keys. 

Under veckan lär vi oss även hur våra Lambda-funktioner kan kommunicera med DynamoDB för att skapa, läsa, uppdatera och ta bort information.

## Mål för veckan:

1. Förstå vad en databas är och varför vi behöver persistent lagring.
2. Förstå skillnaderna mellan relationsdatabaser och NoSQL.
3. Förstå grunderna i databasmodellering för DynamoDB.
4. Skapa tabeller och arbeta med partition keys och sort keys.
5. Använda AWS SDK för att kommunicera med DynamoDB.
6. Utföra CRUD-operationer mot en DynamoDB-tabell.
7. Integrera DynamoDB i ett serverlessbaserat REST API.
